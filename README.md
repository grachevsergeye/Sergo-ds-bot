A simple Discord bot🤖🤖🤖
----
To run the bot, you first need to log into your MongoDB/Discord account and create a bot in developer mode here.
Once you have created it, you can download this project and open it in your editor/editor.
Then open the console and install all the dependencies.
You will also need to create a .env file with all the keys and IDs of your application.
----
This discord Bot was made with discrod.js, dotenv, mongodb and mongoose.
